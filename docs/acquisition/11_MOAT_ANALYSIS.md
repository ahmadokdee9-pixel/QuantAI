# 11. Moat Analysis

---

## Moat thesis (conservative)

QuantAI’s moat is **specialized decision-system engineering with regression locks**, not proprietary inventory and not a unique foundation model.

---

## Moat components

| Component | Moat strength | Notes |
|-----------|---------------|-------|
| Phase A canonical ranking authority | **High** | Hard to recreate with equal cross-surface consistency + tests |
| Decision calibration + mismatch discipline | **High** | Product feel depends on this; gated offline |
| Credible discount gating | **Medium–High** | Trust differentiator vs badge spam |
| Merchant diversity safeguards | **Medium–High** | Preserves alternatives competitors often collapse |
| Truth / RDR / observation stack | **Medium** | Foundation for repeatability & explainability |
| Stabilization under slow upstream | **Medium** | Operational moat for demos/beta |
| Regression corpus on core | **Medium–High** | Moat is corpus + gates, not “CI runs everything” |
| Dormant intelligence estate | **Low–Medium** | Option value only until activated & proven |
| Brand / distribution | **Low** (today) | Not evidenced as a defensive asset |
| Data network effects | **Low** (today) | No proven exclusive data flywheel |

---

## Not moat (commodity)

- Next.js / React / Vercel  
- Clerk / Supabase / Stripe  
- SerpAPI / Google Shopping-style feeds  
- Generic OpenAI calls  
- Generic saved-product CRUD  

---

## Attack surfaces (how moat erodes)

| Attack | Mitigation posture |
|--------|--------------------|
| Competitor wraps SerpAPI + LLM summarizer | Weaker without Phase A + calibration locks |
| Retailer builds internal recommender | Different problem (single merchant) |
| Latency makes product feel inferior | Must be managed operationally |
| Overclaim dormant AI | Diligence destroys trust — disclose honestly |

---

## What a sophisticated buyer should pay for

Pay for the **decision system and its locks**.  

Do **not** pay:

- a data-marketplace premium for inventory QuantAI does not own  
- an “all engines live” premium for flag-OFF modules  

---

## Moat durability summary

| Horizon | View |
|---------|------|
| 0–12 months | Strong if core stays frozen and demos are reliable |
| 12–36 months | Durable only if latency, distribution, and selective activation improve |
| Without GTM | Moat remains engineering IP, not market power |
