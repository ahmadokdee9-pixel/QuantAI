# 6. AI Intelligence Layers Summary

---

## How to read this document

QuantAI contains a **large intelligence estate**. Acquisition claims must distinguish:

| Layer class | Diligence treatment |
|-------------|---------------------|
| **Live decision core** | Part of the product being sold today |
| **On-path enrichment / trust / value** | Contributes to live results when wired |
| **Dormant / shadow / flag-OFF stacks** | Optional future inventory — **not** live product claims |

---

## Live decision core (sell as product)

| Layer | Function |
|-------|----------|
| Discovery fusion | Multi-merchant offer intake |
| Product enrichment | Attach commerce / trust / value signals |
| Truth / ranking decision records | Structured inputs for ranking & explainability |
| Phase A canonical ranking | Single order authority |
| Merchant diversity | Cross-merchant preservation |
| Decision calibration | Shopper labels + confidence + mismatch rules |
| Discount authenticity gating | Credible-only promotion emphasis |
| Results / compare UI binding | Surfaces that preserve server authority |

---

## Supporting intelligence themes (present in codebase)

Examples of themes embodied across engines and phases (illustrative, not a claim that each is independently live):

- Query / intent interpretation  
- Relevance and product matching  
- Merchant reliability / retailer trust  
- Review credibility signals  
- Real discount / true value estimation  
- Buy vs wait / deal opportunity framing  
- Alternatives and competitive context  
- Personalization / memory preparation (auth paths)  
- Tray integrity and explainability bridges  

Exact activation depends on route wiring and feature flags. Buyers should use a live capability map during diligence.

---

## Dormant / experimental estate

The repository includes extensive phase/engine modules and controlled-activation infrastructure that are **default OFF** in production beta posture.

**Seller rule:** Do not market “200 AI engines live.”  
**Buyer rule:** Treat dormant layers as **optional R&D inventory** with enablement cost and risk.

---

## AI vendor usage

| Use | Dependency |
|-----|------------|
| Compare / copilot / optional commerce AI surfaces | OpenAI API |
| Core ranking authority | Deterministic / signal-driven (not “LLM sorts the grid”) |

QuantAI’s primary differentiator is **deterministic ranking + calibration**, with LLMs as supporting surfaces—not the sole ranker.

---

## Diligence checklist for intelligence claims

1. Ask: is this layer on the frozen live path?  
2. Ask: is there an offline gate or production flag proving it?  
3. Ask: what happens if SerpAPI quality drops?  
4. Reject valuation premiums for unactivated shadow stacks.
