## Product name

**QuantAI**

## Category

AI-assisted commerce decision software (pre-revenue SaaS + IP)

## Core value proposition

QuantAI converts noisy multi-merchant shopping results into a **single coherent buying decision** — ranked, calibrated, and presented with clear labels such as BUY, COMPARE, BEST VALUE, or AVOID.

It is decision software, not a proprietary product catalog and not a marketplace with owned inventory.

## Five strongest capabilities

1. **Canonical ranking** — one order authority across the shopping experience  
2. **Decision calibration** — actionable labels with confidence, not cosmetic badges  
3. **Merchant diversity** — preserves useful cross-retailer alternatives  
4. **Credible discount handling** — emphasizes promotions when evidence supports them  
5. **Runnable product surface** — search, results, compare, save, auth, and billing foundations  

## Technical maturity

QuantAI is a feature-dense **public-beta / sale-candidate** web application with a documented decision core and offline quality gates suitable for technical diligence. Hosting and operations use a modern TypeScript / Next.js stack with standard SaaS providers for auth, data, and billing. Experimental modules may exist behind defaults-off flags and are not claimed as live product.
